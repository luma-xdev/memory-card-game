🧠 Memory Card Game

A fun and interactive Memory Card Game built using Python, Flask, HTML, CSS, and JavaScript.

The goal is simple: find all 8 matching pairs using as few moves as possible! 🎮

---

🎮 Features

- 🃏 16 memory cards
- 🧩 8 matching pairs
- 🔄 Card flip animation
- 🎯 Move counter
- ⏱️ Game timer
- 📊 Pair counter
- 🏆 Win popup
- 🔁 Restart Game button
- 📱 Responsive design for mobile and desktop

▶️ Start the Game

1. Install the requirements

Open your terminal and run:

pip install -r requirements.txt

2. Start the Flask server

Run:

python app.py

You should see something similar to:

Running on http://127.0.0.1:5000

---

🌐 Open the Game

Open your web browser and go to:

http://127.0.0.1:5000

The Memory Card Game will open in your browser. 🎮

GitHub Codespaces

If you are using GitHub Codespaces:

1. Run:

python app.py

2. Open the PORTS tab.
3. Find port 5000.
4. Click Open in Browser.

---

🎯 How to Play

1. Click on a card to reveal it.
2. Click on another card.
3. Find the matching pair.
4. Matching cards stay open.
5. Non-matching cards flip back.
6. Match all 8 pairs to win. 🏆

---

🏆 Winning

When all 8 pairs are matched, the game displays:

You Win! 🎉

It also shows your:

- Total moves
- Completion time

You can then click Play Again to start a new game.
