# 🧠 Memory Card Game

A fun and interactive memory card game built with Python, Flask, HTML, CSS and JavaScript.

## 🎮 Features

- 16 memory cards
- 8 matching pairs
- Card flip animation
- Move counter
- Timer
- Pair counter
- Win popup
- Restart button
- Mobile responsive design

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
