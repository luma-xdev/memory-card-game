# 🧠 Memory Card Game

A simple and interactive memory card game built using Python, Flask, HTML, CSS and JavaScript.

## 🎮 Features

- 16 memory cards
- 8 matching pairs
- Card flip animation
- Move counter
- Timer
- Pair counter
- Win screen
- Restart button
- Responsive design

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
